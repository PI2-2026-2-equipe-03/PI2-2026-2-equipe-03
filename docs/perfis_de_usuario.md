**Perfis de Usuário**  
---

Este documento especifica os tipos de usuários existentes no sistema TaGravado, assim como seus papéis e permissões

**Usuário** 

**Descrição geral:** jogador comum que utiliza o sistema para buscar quadras. Tem acesso apenas ao próprio perfil e aos próprios dados.

**Permissões:**

* Visualizar e editar o próprio perfil  
* Buscar visualizar e baixar gravações  
* Solicitar recuperação ou alteração de senha   
* Solicitar cadastro como Cliente (dono de quadra) 

**Cliente/Dono de Quadra** 

**Descrição geral:** Surge a partir da aprovação de uma solicitação feita por um administrador. Pode gerenciar exclusivamente as quadras que lhe pertencem.

**Permissões:**

* Tudo o que um Usuário pode fazer  
* Criar, editar e excluir *apenas as quadras de sua propriedade*  
* Visualizar o dashboard de métricas de uso referente às suas próprias quadras, para apoiar decisões estratégicas   
* Solicitar recuperação ou alteração de senha 

**Administrador**

**Descrição geral:** Conta dos desenvolvedores/equipe responsável pela operação do sistema. Tem acesso irrestrito a todas as quadras e usuários.

**Permissões:**

* Criar, editar e excluir quadras de qualquer Cliente  
* Avaliar, aprovar ou indeferir solicitações de Usuário para se tornar Cliente   
* Visualizar o dashboard de métricas consolidadas de uso de todo o sistema, de todos os Clientes   
* Solicitar recuperação ou alteração de senha
