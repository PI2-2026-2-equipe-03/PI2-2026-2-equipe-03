
## Introdução

No dia 26 de Agosto foi realizada a entrevista online, via google meet, com o cliente Flávio Renan, dono da Arena Dunnas Beach, acompanhado pela equipe do projeto.

A reunião foi feita com propósito de levantar os principais requisitos funcionais do sistema a ser desenvolvido, além de alinhar as ideias discutidas anteriormente pela equipe

## Sobre a entrevista

Durante o encontro foi discutido as principais necessidades do cliente, O maior entrave percebido foi a falta de uma automatização das gravações de jogos realizados pelos frequentadores do espaço. O proprietário ressaltou que não busca uma solução complexa, mas sim um software funcional e prático. Diante disso, foi proposta a ideia de um sistema simples onde usuário possa acessar os vídeo gravados de qualquer horário, seja pelo celular ou pelo computador, junto também com um módulo de marcação de horários das quadras disponíveis

Foi apresentado também na entrevista o protótipo do sistema versão mobile, a página inicial, as arenas da cidade e os horários disponíveis, que foram muito bem recebidos pelo cliente, após a apresentação, foi discutido a data para o reconhecimento do local pelos participantes do projeto e do modelos das câmeras que serão utilizadas

## Considerações finais

Com base nas informações coletadas, a equipe se reunirá para estruturar a arquitetura do sistema e definir os recursos tecnológicos que serão empregados. Essa etapa garantirá o alinhamento do escopo e prevenirá alterações bruscas nas fases finais de desenvolvimento do projeto.
