# Protótipo de Alta Fidelidade — TaGravado

## Objetivo

O protótipo de alta fidelidade do TaGravado foi desenvolvido para representar visualmente as principais telas e fluxos do sistema, permitindo validar a navegação e a interação com o cliente antes da implementação.

## Protótipo

O protótipo foi desenvolvido no Figma e contempla as principais telas do sistema incluindo os fluxos do usuário, do organizador e da área administrativa.

**Link do protótipo no Figma:**  
https://www.figma.com/design/zLz9JwG8iKX8twcxCNoUO2/TaGravado?node-id=0-1&t=ZQ1C6uP4FKJnQgth-1

## Telas desenvolvidas

O protótipo contém no mínimo, 10 telas em alta fidelidade, contemplando as principais funcionalidades do sistema.

Entre as telas desenvolvidas estão:

1. Login
2. Criar conta
3. Início
4. Arenas
5. Quadras
6. Horário e data
7. Resultados
8. Painel administrativo
9. Gerenciar quadras
10. Gerenciar câmeras

Além dessas telas, o protótipo contempla as funcionalidades relacionadas ao perfil do usuário, à solicitação para se tornar organizador e à análise das solicitações pelo administrador.

## Navegação

As telas do protótipo possuem conexões de navegação clicáveis, permitindo percorrer os principais fluxos do sistema.

### Fluxo do usuário

Login → Início → Busca de arena → Seleção da arena → Seleção da quadra → Horário e data → Resultados

### Fluxo para se tornar organizador

Login → Perfil → Tornar-se um organizador → Solicitação de cadastro

O usuário que deseja utilizar o sistema para gerenciar uma arena pode acessar a opção "Torne-se um organizador" em seu perfil e enviar uma solicitação.

### Fluxo administrativo

Login → Painel administrativo → Solicitações de organizadores

O administrador analisa as solicitações enviadas pelos usuários que desejam se tornar organizadores.

A solicitação pode ser:

- **Aprovada:** o usuário passa a ter acesso às funcionalidades de organizador;
- **Rejeitada:** a solicitação não é aprovada pelo administrador.

Após a aprovação, o organizador poderá utilizar as funcionalidades destinadas ao gerenciamento da arena, incluindo o gerenciamento de quadras e câmeras.

## Validação

O protótipo foi apresentado para validação das telas, dos fluxos e da navegação junto ao cliente, permitindo verificar se a proposta está de acordo com as necessidades identificadas para o sistema.

Os ajustes identificados durante a validação foram considerados no desenvolvimento do protótipo.
